# 🌍 NASA TEMPO – Real-Time Air Quality Intelligence Dashboard

> Transforming NASA Earth Observation data into actionable environmental insights.

NASA TEMPO is an interactive environmental monitoring platform developed for the **NASA Space Apps Challenge**. By integrating geospatial visualization with environmental analytics, the platform enables users to explore air quality patterns, identify pollution hotspots, and better understand the impact of pollutants such as **NO₂, O₃, SO₂, CO, and PM2.5**.

---

## ✨ Key Highlights

- 🛰️ Satellite-inspired air quality visualization
- 🌫️ Multi-pollutant monitoring and analysis
- 📊 Real-time AQI tracking and trend insights
- 🗺️ Interactive geospatial heatmaps
- ⏳ Time-based pollution playback and exploration
- 🌍 Supports environmental awareness and data-driven decision-making

---

## 🛠️ Technology Stack

### Frontend
- **React.js** – Interactive and component-based UI
- **TypeScript** – Type-safe development
- **Tailwind CSS** – Responsive and modern styling
- **Leaflet.js** – Geospatial map visualization
- **Chart.js / Recharts** – AQI trends and analytics

### Backend
- **Node.js & Express.js** – REST API development
- **NASA TEMPO API / Environmental Datasets** – Air quality and atmospheric data retrieval
- **Data Processing Engine** – Pollutant aggregation, AQI calculation, and temporal filtering
- **Caching Layer** – Optimized data access and faster response times

### Data & Analytics
- Real-time pollutant monitoring (**NO₂, O₃, SO₂, CO, PM2.5**)
- AQI computation and classification
- Time-series analysis and trend visualization
- Geospatial pollution heatmap generation
